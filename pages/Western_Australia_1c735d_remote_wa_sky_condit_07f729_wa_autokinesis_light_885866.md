## Introduction

A common reason for reports of “darting” or “zig-zagging” lights on remote Western Australian roads is not that the light is physically moving, but that the observer is experiencing **autokinesis**. This is a well-documented visual illusion in which a single stationary point of light appears to drift, jump or change direction when viewed against a dark, featureless background. Aviation authorities teach pilots to recognise the effect because it can be convincing enough to influence judgement during night flying.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.faa.gov/air_traffic/publications/atpubs/aip_html/chap8_section_1.html" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: faa.gov">[faa.gov]</a><span class="citation-popover" role="note"><span class="citation-popover-source">faa.gov</span><span class="citation-popover-title">Federal Aviation Administration Fitness for Flight</span><span class="citation-popover-snippet">Federal Aviation Administration Fitness for Flight</span></span></span>

The mechanism is especially relevant to [Western Australia]({{ 'what-really-happened-in-western/' | relative_url }})'s UFO history because vast stretches of the state's highways and pastoral regions provide almost ideal conditions for the illusion. Long periods of driving through darkness, sparse roadside landmarks and isolated lights on a distant horizon make it unusually difficult to judge whether a light is genuinely moving or only appears to be.

## What autokinesis does to a lone light

Autokinesis is the apparent movement of a stationary light seen against an otherwise dark scene. The light itself does not move, but the observer experiences subtle drifting, wobbling, short darts or slow directional changes.

The effect is strongest when:


<div class="content-enhancement content-enhancement--comparison" markdown="1">

* only one bright light is visible;
* there are few surrounding stars, buildings or landscape features for comparison;
* the observer stares continuously at the light for several seconds; and
* the surrounding environment provides almost no stable visual references.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.faa.gov/air_traffic/publications/atpubs/aip_html/chap8_section_1.html" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: faa.gov">[faa.gov]</a><span class="citation-popover" role="note"><span class="citation-popover-source">faa.gov</span><span class="citation-popover-title">Federal Aviation Administration Fitness for Flight</span><span class="citation-popover-snippet">Federal Aviation Administration Fitness for Flight</span></span></span>

</div>

Researchers have investigated the phenomenon for many decades because it illustrates how the brain estimates motion. Human eyes are never perfectly still. Tiny involuntary eye movements normally go unnoticed because the visual system constantly compares them with the surrounding scene. When almost all reference points disappear, the brain can misattribute these small movements to the light itself rather than to the observer's own visual system. Neuroimaging studies have shown that motion-processing regions of the brain become active even though the light remains physically stationary.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://pubmed.ncbi.nlm.nih.gov/15878673/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pubmed.ncbi.nlm.nih.gov">[PubMed]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pubmed.ncbi.nlm.nih.gov</span><span class="citation-popover-title">Pub Med Imaging the visual autokinetic illusion with f MRI</span><span class="citation-popover-snippet">Imaging the visual autokinetic illusion with fMRI - PubMedAugust 1, 2005...</span><span class="citation-popover-meta">Published: August 1, 2005</span></span></span>

Importantly, autokinesis changes **perception**, not reality. A witness who sincerely reports that a light zig-zagged may accurately describe what they experienced without the light having performed extraordinary manoeuvres.

## Why remote WA roads create ideal viewing conditions

Western Australia contains some of Australia's longest and least populated roads. Drivers can spend hours travelling through country where there are few houses, trees, hills or illuminated structures.

These conditions encourage autokinesis for several reasons.

First, the horizon is often exceptionally open. A distant aircraft landing light, communications tower, mining installation or bright planet may be viewed against an almost completely black sky, leaving few fixed points for comparison.

Second, prolonged driving naturally encourages visual fixation. A driver may watch the same distant light for many seconds while travelling towards it. Aviation guidance notes that prolonged fixation greatly increases the likelihood of autokinesis becoming noticeable.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.faa.gov/sites/faa.gov/files/19_phak_ch17.pdf" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: faa.gov">[Federal Aviation Administration]</a><span class="citation-popover" role="note"><span class="citation-popover-source">faa.gov</span><span class="citation-popover-title">Federal Aviation Administration PHAK Chapter 17</span><span class="citation-popover-snippet">Federal Aviation Administration PHAK Chapter 17</span></span></span>

Third, darkness removes depth cues. During daylight the brain constantly estimates distance using terrain, vegetation, buildings and shadows. At night these cues largely disappear, making it difficult to judge whether a light is nearby and small or distant and powerful.

Finally, fatigue can make sustained concentration on isolated lights more likely during long-distance driving, although fatigue itself is a separate issue from autokinesis.

These factors help explain why reports from remote roads often describe lights that appear to hover briefly before suddenly sliding sideways or making abrupt changes of direction, despite no independently verified movement.

## Why the illusion can seem so convincing

One reason autokinesis has remained relevant in aviation and UFO investigations is that the apparent movement often feels completely real.

Observers commonly describe a stationary light as:


<div class="content-enhancement content-enhancement--phrase-stack" markdown="1">

* drifting slowly across the horizon;
* making sudden sideways jumps;
* tracing small circles;
* moving towards or away from them; or
* repeatedly stopping and starting.

</div>

The illusion can persist even when the observer knows about it intellectually. That is why pilot training does not simply tell aviators that the effect exists—it teaches practical techniques for avoiding fixation and relying on multiple visual references rather than a single isolated light.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.faa.gov/air_traffic/publications/atpubs/aip_html/chap8_section_1.html" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: faa.gov">[Federal Aviation Administration]</a><span class="citation-popover" role="note"><span class="citation-popover-source">faa.gov</span><span class="citation-popover-title">Federal Aviation Administration Fitness for Flight</span><span class="citation-popover-snippet">Federal Aviation Administration Fitness for Flight</span></span></span>

In UFO reports, this means that witness confidence alone cannot determine whether unusual motion actually occurred. A confident description may accurately reflect perception while remaining an inaccurate description of the light's physical behaviour.

## How to separate eye movement from real motion

Autokinesis has identifiable characteristics that distinguish it from genuine movement.

A light is more likely to be affected by autokinesis if:


<div class="content-enhancement content-enhancement--insight-grid" markdown="1">

* only one isolated light is visible;
* apparent movement begins after several seconds of staring;
* the movement is irregular rather than following a steady course;
* different observers disagree about the exact direction of movement; or
* looking away briefly causes the apparent motion to stop or change.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.faa.gov/sites/faa.gov/files/19_phak_ch17.pdf" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: faa.gov">[Federal Aviation Administration]</a><span class="citation-popover" role="note"><span class="citation-popover-source">faa.gov</span><span class="citation-popover-title">Federal Aviation Administration PHAK Chapter 17</span><span class="citation-popover-snippet">Federal Aviation Administration PHAK Chapter 17</span></span></span>

</div>

Conversely, genuine movement is more likely if the light changes position relative to multiple stars, hills, buildings or other fixed landmarks, or if several independently positioned observers record the same displacement.

Modern cameras can also be informative. Although cameras have their own limitations, a fixed camera may show a light remaining stationary even when the observer remembers it moving dramatically. Such discrepancies are consistent with autokinesis because the illusion occurs within human visual perception rather than in the external scene.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.ufouap.net/en/explainers/autokinesis-stationary-light-illusion" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: ufouap.net">[ufouap.net]</a><span class="citation-popover" role="note"><span class="citation-popover-source">ufouap.net</span><span class="citation-popover-title">Autokinesis: Why a Stationary Light Seems to Move &#124; Global UFO Archive</span><span class="citation-popover-snippet">July 11, 2026...</span><span class="citation-popover-meta">Published: July 11, 2026</span></span></span>

## What this means for Western Australia's UFO reports

Autokinesis does not explain every unusual light reported in Western Australia. Some sightings involve multiple objects, radar information, structured craft descriptions or independent witnesses observing genuine movement relative to terrain. Those cases require separate evaluation.

However, the mechanism is particularly important when reports share several features:


<div class="content-enhancement content-enhancement--insight-grid" markdown="1">

* a single bright light;
* observation from an isolated road at night;
* few visible landmarks;
* prolonged watching; and
* dramatic claims of darting or hovering based solely on visual observation.

</div>

Within the broader history of Western Australian UFO reports, autokinesis therefore provides a well-established perceptual explanation for one recurring pattern of sightings. It neither proves that every report is misidentified nor dismisses witnesses as unreliable. Instead, it demonstrates that remote viewing conditions can produce compelling experiences in which a genuinely stationary light appears to perform extraordinary manoeuvres. Recognising this distinction helps separate cases that primarily reflect known properties of human perception from those that warrant closer investigation on other grounds.

    if (picker) picker.classList.remove('fr-ebay-market-picker--open');
  }
  function availableMarkets(section) {
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      return Array.prototype.slice.call(select.options)
        .map(function (option) { return option.value; })
        .filter(function (marketId) { return !!markets[marketId]; });
    }
    return Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]'))
      .map(function (button) { return button.getAttribute('data-ebay-market-button'); })
      .filter(function (marketId) { return !!markets[marketId]; });
  }
  function applyMarket(section, marketId, persist) {
    var available = availableMarkets(section);
    if (available.indexOf(marketId)< 0) marketId = available[0] || defaultMarket;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-localized-link]')).forEach(function (link) {
      var query = link.getAttribute('data-ebay-query') || '';
      var reference = link.getAttribute('data-ebay-reference') || '';
      link.setAttribute('href', buildUrl(query, reference, marketId));
    });
    var select = section.querySelector('[data-ebay-market-select]');
    if (select && available.indexOf(marketId) >= 0) select.value = marketId;
    var selectedText = marketId;
    if (select && select.selectedIndex >= 0) selectedText = select.options[select.selectedIndex].text;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-flag], [data-ebay-trigger-market-flag]')).forEach(function (flag) {
      flag.className = flagClass(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-trigger-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-domain-label]')).forEach(function (label) {
      label.textContent = domainLabel(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
      button.setAttribute('aria-selected', button.getAttribute('data-ebay-market-option') === marketId ? 'true' : 'false');
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      var active = button.getAttribute('data-ebay-market-button') === marketId;
      button.setAttribute('aria-pressed', active ? 'true' : 'false');
    });
    section.setAttribute('data-ebay-selected-market', marketId);
    if (persist) {
      try { if (window.localStorage) localStorage.setItem('phoenix-ebay-market', marketId); } catch (err) {}
    }
    closeMenu(section);
  }
  sections.forEach(function (section) {
    if (section.getAttribute('data-ebay-localized-init') === '1') return;
    section.setAttribute('data-ebay-localized-init', '1');
    var available = availableMarkets(section);
    var marketId = defaultMarket;
    if (window.PhoenixAffiliateLocation && window.PhoenixAffiliateLocation.inferMarket) {
      marketId = window.PhoenixAffiliateLocation.inferMarket(available, {
        storageKey: 'phoenix-ebay-market',
        defaultMarket: defaultMarket
      });
    } else if (available.indexOf(defaultMarket)< 0) {
      marketId = available[0] || defaultMarket;
    }
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      select.addEventListener('change', function () {
        applyMarket(section, select.value, true);
      });
    }
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var menu = section.querySelector('[data-ebay-market-menu]');
    if (trigger && menu) {
      trigger.addEventListener('click', function (event) {
        event.stopPropagation();
        var expanded = trigger.getAttribute('aria-expanded') === 'true';
        menu.hidden = expanded;
        trigger.setAttribute('aria-expanded', expanded ? 'false' : 'true');
        var picker = trigger.closest('.fr-ebay-market-picker');
        if (picker) picker.classList.toggle('fr-ebay-market-picker--open', !expanded);
      });
      Array.prototype.slice.call(menu.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
        button.addEventListener('click', function (event) {
          event.stopPropagation();
          applyMarket(section, button.getAttribute('data-ebay-market-option'), true);
        });
      });
      document.addEventListener('click', function () { closeMenu(section); });
    }
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      button.addEventListener('click', function () {
        applyMarket(section, button.getAttribute('data-ebay-market-button'), true);
      });
    });
    applyMarket(section, marketId, false);
  });
})();
